# Duo

Plateforme de bureau pour jouer à deux en réseau local, sur macOS et Windows. Les jeux (2D, 3D, isométriques) sont créés un par un par un studio d'agents IA, chacun à partir d'un cahier des charges validé.

- Organisation, équipe et règles du studio: [`CLAUDE.md`](CLAUDE.md)
- Fiches de l'équipe: [`.claude/agents/`](.claude/agents/)
- Avancement: [`docs/feuille-de-route.md`](docs/feuille-de-route.md)
- Modèle de cahier des charges: [`docs/modeles/cahier-des-charges.md`](docs/modeles/cahier-des-charges.md)
- Crédits et licences des ressources externes: [`CREDITS.md`](CREDITS.md)
