# Dialogues (lot L3)

Un dialogue est un graphe (`src/donnees/schemas/dialogue.ts`). L'état ne porte que le nœud courant de chaque joueur (`player.talk`); le défilement lettre par lettre, le babil et « tout afficher » sont locaux (lot L7). À écrire: choisir le dialogue (priorité, `when`, `once`), avancer, appliquer les effets des options.
